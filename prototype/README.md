# 선물 · 화면·흐름 개선 시제품 v0.2.1

**선배에게 물어봐. 후배가 선배가 되는 날까지.**

이 패키지는 실제 서비스 연결 전, 화면·말투·상담 흐름을 확인하는 로컬 시제품입니다.

기존 v0.1의 단일 HTML과 설계를 이어서 수정했습니다. 이번 환경에서는 브라우저 접근이 차단되어 실제 PC·모바일 화면 검토를 완료하지 못했습니다. 변경 내용은 `CHANGELOG.md`, 검증 범위는 `QA_NOTES.md`를 확인하세요.

## 바로 확인하기

1. `index.html` 파일을 브라우저로 엽니다.
2. 닉네임을 입력하거나 **엠버로 먼저 둘러보기**를 선택합니다.
3. 홈의 네 가지 카테고리 중 하나를 눌러 질문합니다.
4. **선배에게 묻기** → 요약 수정 → 추가 메시지 직접 선택 → 동의 → **확인한 내용으로 시연 저장**을 누릅니다. 추가 메시지는 기본 선택하지 않습니다.
5. **운영자 답변 화면 체험**에서 답변을 직접 입력합니다.
6. 사용자 **알림**에서 답변을 확인하고, **배운 점 남기기**로 성장기록을 살펴봅니다.

PC에서 모바일 폭도 비교하려면 `REVIEW.html`을 열어 390px·320px·PC 폭을 전환할 수 있습니다. 화면 폭만 바꾸며 실제 모바일 키보드·터치를 재현하지는 않습니다.

설치나 외부 라이브러리가 필요하지 않습니다. 외부 폰트·이미지·API를 불러오지 않습니다. 브라우저나 보안 설정에 따라 로컬 HTML 실행 및 저장이 제한될 수 있습니다.

## 아직 연결되지 않은 부분

실제 생성형 AI, 검수된 100문100답 검색, 회원 로그인, 사용자별 서버 저장, 다른 기기 동기화, 실제 선배 전송, 푸시·이메일 알림, 결제는 연결되지 않았습니다.

운영자 화면은 보안 로그인 없이 누구나 전환할 수 있는 **시연용 화면**입니다. 실제 사용자나 거래처의 데이터를 수집하는 용도로 배포하지 마세요. 이 시제품은 실제 세무·노무 판단을 제공하기 위한 서비스가 아닙니다.

## 이번에 반영한 확정사항

- 서비스명은 **선물(선배에게 물어봐)**입니다.
- 슬로건은 **후배가 선배가 되는 날까지**입니다.
- 선배가 먼저 말을 거는 홈 화면을 사용합니다.
- 닉네임을 자연스럽게 부릅니다.
- 새싹·나무 그림은 **닉네임 카드 안의 작은 표시**에만 사용합니다.
- 나머지 화면에는 나무·물주기·영양분·화분·숲·열매 같은 컨셉을 넣지 않습니다.
- 사용량 제한과 결제는 OFF입니다. 제공 횟수는 아직 정하지 않았습니다.
- 질문 수나 같은 질문의 반복을 업무 능력 점수로 해석하지 않습니다.

## 내 대화 즐겨찾기

대화 오른쪽의 별 버튼으로 즐겨찾기를 추가하거나 해제합니다. **즐겨찾기만 보기**를 켜면 선택한 대화만 모아보며, 검색·카테고리 필터를 함께 사용할 수 있습니다. 즐겨찾기를 해제해도 대화는 삭제되지 않습니다. 같은 브라우저의 로컬 기록에 저장되며 다른 기기로 동기화되지 않습니다.

## 그림이 달라지는 기준

닉네임 카드의 작은 그림은 선택한 경력에 따라 달라집니다. 프로필에서 경력을 변경하고 저장하면 바로 반영됩니다. 질문 수·배운 점 기록 수와 무관하며 업무 능력이나 멘토 자격을 평가하는 표시는 아닙니다.

| 선택한 경력 | 작은 그림 |
|---|---|
| 이제 막 시작했어 | 새싹 |
| 1년 차 | 잎이 더 자란 새싹 |
| 2년 차 | 작은 나무 |
| 3년 차 | 자란 나무 |
| 4년 차 이상 | 풍성한 나무 |

## 데이터와 개인정보

데이터는 브라우저 `localStorage`의 `seonmul.prototype.v1`에만 저장됩니다. 별도의 서버로 전송하지 않습니다. 브라우저 데이터 삭제·시크릿 모드·저장 제한 등에 따라 사라질 수 있으며 계정 기반 저장이 아닙니다. 공유 PC에는 실제 개인정보를 입력하지 마세요.

상담 요청은 마지막 사용자 질문을 요약란의 초기값으로 넣습니다. 사용자는 그 내용을 직접 수정하고, 추가로 공유할 메시지를 선택합니다. 추가 대화는 기본 선택하지 않습니다. 요약이나 선택 메시지가 바뀌면 동의가 해제되어 다시 확인해야 합니다. 현재 대화 밖의 기록은 보내지 않습니다. 상담·답변 저장 실패 시 완료 상태로 넘어가지 않으며 입력 화면을 유지합니다.

**상담에 내용을 공유하는 동의**와 **그 내용을 다른 사람에게 답하는 노하우로 재사용하는 동의**는 구분합니다. 이 시제품의 노하우는 모두 검토 전 초안이며 AI가 사용하지 않습니다.

v0.1의 저장 키·데이터 버전을 유지합니다. 같은 브라우저의 같은 출처에서 열면 기존 기록을 읽습니다. 파일 이동이나 다른 서버 주소에서 기록이 이어진다고 보장하지 않습니다. 홈·채팅의 작성 중 질문과 상담 요약 초안은 열린 탭의 화면 이동 동안만 유지합니다. 새로고침하거나 탭을 닫으면 초안은 사라집니다.

- `MENTOR_SYSTEM_PROMPT.md`: 실제 AI 연결 시 사용할 멘토 지침 초안

- `CHANGELOG.md`: 이번 변경 내용
- `REVIEW.html`: PC에서 모바일·PC 폭을 비교하는 별도 검토 도구
