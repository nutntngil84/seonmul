# v0.2.1 추가 확인

경력 5개 선택값에서 서로 다른 기존 SVG 그림이 생성되고, 배운 점 개수를 바꿔도 해당 경력의 그림은 유지됨을 함수 실행으로 확인했다. JavaScript 구문도 확인했다. 실제 브라우저 화면 검증은 기존 접근 제한으로 미완료다.

추가로 즐겨찾기 등록·해제, 검색·카테고리와 결합한 필터, 빈 목록 안내, 저장 데이터 직렬화·재로딩, 저장 실패 시 되돌림을 격리된 함수 실행으로 확인했다. 생성 HTML에서 별 버튼이 대화 열기 버튼 안에 중첩되지 않았음을 파싱으로 확인했다. 실제 브라우저 동작 검증은 아니다.

# v0.2 검토 기록 · 2026-09-20

## 실제 실행 상태

README.md, IMPLEMENTATION_BRIEF.md, index.html 및 나머지 설계 파일을 읽고 기존 코드를 수정했다.

로컬 HTTP 서버는 시작했으나 연결된 브라우저가 로컬 주소를 차단했다. 공유 경로의 HTML 파일 직접 열기도 URL 정책으로 차단되었다. 정책을 우회하거나 다른 브라우저로 실행하지 않았다.

**원본과 수정본 모두 실제 브라우저 렌더링·스크린샷·PC/모바일 클릭 흐름 검증은 완료하지 못했다.** 아래 검사는 실제 DOM·레이아웃 엔진·터치 기기·실제 저장소를 사용한 검증이 아니다. v0.1에 들어 있던 이전 검증 기록을 이번 검증 결과로 재사용하지 않았다.

## 실제 브라우저에서 남은 검토

`index.html`을 브라우저로 열어 확인한다. PC에서 창 너비 비교는 `REVIEW.html`로도 가능하다. 이 도구는 실제 휴대폰을 대신하지 않는다.

1. PC 1440/1024px: 닉네임 입력 → 홈 카테고리 → 질문 → 긴 예시 답변 첫 부분과 입력창 확인.
2. 모바일 390/320px: 같은 흐름의 가로 넘침·버튼 잘림·하단 메뉴 겹침 확인. 실제 휴대폰에서 키보드·줄바꿈·한글 조합·전송 확인.
3. 초안: 홈·채팅에 입력하다 다른 메뉴에 갔다 돌아오면 유지되는지 확인. 새로고침은 초안 유지 범위가 아님.
4. 상담: 요약 수정, 추가 대화 선택·해제, 공유 범위 표시, 동의 재확인, 저장 버튼, 취소 후 재열기, 긴 대화 스크롤 확인.
5. 상담 이후: 원래 대화 이어가기 → 운영자 시연 답변 작성 → 로컬 알림 → 답변 시연 표시 → 배운 점 저장.
6. 성장기록: 배운 점 확인·수정·삭제, 질문으로 돌아가기, 피드백 출처 상담 열기, 기간 변경.
7. 접근성: Tab·Shift+Tab·Escape, 모달 초점 이동, 화면 확대 200%, 스크린리더 라벨·알림 읽기.
8. 저장: 실제 localStorage 새로고침·탭 재열기·용량 제한. 파일 실행과 HTTP 실행의 출처가 다르면 기존 기록이 이어지지 않을 수 있음.

## 이번 범위 밖

실제 AI·로그인·서버 DB·권한 분리·다른 기기 동기화·외부 알림·실제 선배 전송·결제는 모두 미연결이다. 이 결과는 출시·보안 검증이 아니다. 화면 검토 후 인증·권한 → 서버 저장 → AI → 상담 알림 순서를 따른다.
