# v0.2.1 · 경력별 그림 수정·즐겨찾기 추가

- 원인: 그림이 경력 대신 배운 점 개수를 기준으로 선택되어, 기록이 없으면 경력과 무관하게 새싹으로 표시됐다.
- 수정: 기존 그림 5종을 선택한 경력 5단계에 연결했다. 질문·기록 개수는 그림에 영향을 주지 않는다.
- 내 대화: 각 대화의 별 버튼으로 즐겨찾기 추가·해제, 즐겨찾기만 보기 제공. 검색·카테고리와 함께 적용하며 로컬 기록에 저장한다.
- 별 버튼은 대화 열기와 분리했다. 즐겨찾기 해제 시 원래 대화는 유지하며 저장 실패 시 상태를 되돌린다.

# v0.2 · 화면과 사용 흐름 개선

기존 v0.1의 단일 HTML을 수정했다. 프레임워크 교체나 실제 서비스 연결은 하지 않았다.

| 화면/흐름 | 기존 코드에서 확인한 불편 | 수정 내용 |
|---|---|---|
| 홈 | 모바일 글자가 9~13px까지 작아짐 | 주요 입력·본문 16px, 안내 14px 중심으로 조정. 모바일 선택지를 세로형 카드로 배치 |
| 홈 인사 | 재접속하면 직전 인사 기억을 잃음 | 저장된 마지막 문구를 참고해 반복 방지. 입력 중 문구 유지 |
| 입력 | 다른 메뉴를 다녀오면 작성 중 질문이 사라짐 | 열린 탭에서 홈·대화별 질문 초안 유지 |
| 채팅 | 작은 화면의 제목·상담 버튼이 한 줄로 밀집 | 상담 버튼 별도 행, 대화 스크롤과 하단 입력 영역 분리 |
| 답변 읽기 | 긴 답변이 나오면 맨 아래로 이동 | 새 답변 첫 부분으로 이동. 대화 재열기는 최신 위치 |
| 모바일 입력 | Enter를 일괄 전송으로 처리 | 터치 기기 Enter는 줄바꿈, 버튼으로 전송. PC 단축키 유지 |
| 상담 공유 | 요약을 고쳐도 원래 질문이 기본 공유됨 | 요약·프로필만 기본 공유, 추가 메시지는 직접 선택 |
| 상담 동의 | 내용을 바꿔도 기존 동의 유지 | 요약·선택을 바꾸면 동의 해제. 공유 범위·버튼 상태 연동 |
| 상담 모달 | 목록·본문까지 중첩된 스크롤 | 단일 세로 스크롤, 접는 메시지 목록, 상하단 동작 영역 유지 |
| 상담 후 | 대화로 돌아가는 연결 부족 | 이어서 대화하기·성장기록 보기 연결 |
| 시연 구분 | 임의 운영자 입력이 제니 이름으로 표시됨 | ‘선배 답변 · 운영자 입력 · 시연’으로 표시, 답변 시각 제공 |
| 성장기록 | 횟수가 먼저 보이고 질문으로 돌아가기 어려움 | 배운 점·피드백 우선, 최근 질문 연결, 횟수는 접어서 표시 |
| 자기기록 | 수정·개별 삭제 불가 | 기존 기록 수정·확인 후 삭제. 연결 대화·상담 유지 |
| 저장 오류 | 실패 후에도 상담·답변 완료로 이동 | 상담·답변·자기기록 저장 실패 시 변경 취소 및 입력 유지 |

유지: 선배가 먼저 말 거는 홈, 닉네임 호칭, 슬로건, 네 카테고리, 실무 노하우·격려 중심 예시 응답, 닉네임 카드 안의 작은 그림, 질문 횟수로 실력 평가 금지, 제한·결제 OFF, 확인·동의 후 상담 시연.

위 내용은 코드 수정 내역이며 실제 렌더링 검증 결과가 아니다. 검증 한계는 `QA_NOTES.md`를 확인한다.
